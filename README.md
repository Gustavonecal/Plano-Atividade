# TaskFlow Acadêmico

Projeto simples de gerenciamento de tarefas acadêmicas, criado para servir como base de um **PGCS — Plano de Gestão e Configuração de Software**.

## Objetivo

Permitir que o usuário cadastre tarefas com prazo e prioridade, marque tarefas como concluídas, filtre a lista e exclua itens. Os dados ficam salvos localmente no navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage do navegador

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Cadastre algumas tarefas para testar.

Não é necessário instalar dependências.

## Funcionalidades

- Cadastro de tarefa
- Definição de prazo
- Prioridade baixa, média ou alta
- Marcação de tarefa concluída
- Filtro por status
- Exclusão de tarefa
- Limpeza de tarefas concluídas
- Persistência local no navegador

## Estratégia de versionamento sugerida

- `main`: versão estável
- `develop`: integração das alterações
- `feature/nome-da-funcionalidade`: novas funcionalidades
- `fix/nome-do-ajuste`: correções

Versões sugeridas: `v1.0.0`, `v1.1.0`, `v2.0.0`.

## Exemplos de commits

- `feat: adiciona cadastro de tarefas`
- `feat: adiciona filtro por status`
- `fix: corrige exclusão de tarefa`
- `docs: atualiza documentação do projeto`
